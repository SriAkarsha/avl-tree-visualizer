# AVL Tree Visualizer 🌳

A web-based application to visualize the working of an AVL Tree.
Users can insert and delete values and observe how the tree remains balanced
through rotations.

## Features
- Insert nodes into AVL Tree
- Delete nodes from AVL Tree
- Automatic self-balancing
- Visual representation using SVG
- Displays rotation operations

## Technologies Used
- HTML
- CSS
- JavaScript
- SVG
- GitHub Pages

## How to Run
1. Clone the repository
2. Open `index.html` in a browser

## Use Case
Helps students understand AVL Tree balancing and rotations visually.
